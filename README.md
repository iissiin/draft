# draft_undo: отмена удаления черновика

## Запуск

Требования: Flutter (версия: Flutter 3.41.9)

```bash
cd draft_undo
flutter pub get
flutter run
```

## Действия и их условия

| Действие | Условие и результат |
| --- | --- |
| edit | Есть сохранённый черновик (`draft != null`); создаётся временная копия `editCopy` |
| save | Редактор открыт; заголовок после удаления пробелов по краям 1–40 символов, текст до 200; иначе ошибка под полем и редактор остаётся открытым. При успехе `draft` заменяется данными копии |
| cancel | Копия отбрасывается, сохранённый `draft` не меняется |
| delete | Есть сохранённый черновик; его копия кладётся в `deletedDraft`, `draft` становится `null`, показывается «Черновик удалён» |
| restore | Есть `deletedDraft` и `draft == null`; черновик возвращается с id=1 и значениями из снимка, `deletedDraft` очищается, повторное восстановление недоступно |

## Пять ручных проверок

Автотестов и CI нет, по ТЗ проверки выполнены вручную. Каждая проверка проходилась в одном запуске, по порядку.

| № | Действие | Ожидаемый результат | Фактический результат |
| --- | --- | --- | --- |
| 1 | Изменить заголовок на «Новый план кружка», в тексте ввести две строки («Идея 1», «Идея 2»), нажать «Сохранить» | Редактор закрывается, список показывает новый заголовок и обе строки текста | Пройдено |
| 2 | Изменить заголовок и текст, нажать «Отмена», снова открыть редактор | Список показывает прежний сохранённый заголовок; в редакторе поля содержат сохранённые значения | Пройдено|
| 3 | Заменить заголовок только пробелами, нажать «Сохранить» | Ошибка «Введите заголовок» под полем, редактор открыт, сохранённые данные не изменились | Пройдено |
| 4 | Изменить заголовок на «Перед удалением», сохранить, нажать корзину | Карточка пропала, показано «Черновик удалён» и кнопка «Вернуть черновик», `deletedDraft` содержит копию с id=1 | Пройдено |
| 5 | Нажать «Вернуть черновик» | Возвращается черновик с id=1 и последними сохранёнными значениями («Перед удалением»), `deletedDraft` равен `null`, кнопки «Вернуть» больше нет | Пройдено |


# Журнал использования AI

AI использовался: Claude (Anthropic), чат claude.ai. Применялся для разбивки задания на этапы, подсказок по архитектуре и примеров кода. Весь код запускала и проверяла сама. Чужие данные и личная информация в AI не отправлялись.

| Задача | Полученная помощь | Что я изменила | Как проверила |
| --- | --- | --- | --- |
| Разбить ТЗ на этапы, выбрать архитектуру| План из 7 этапов; слои `domain` / `data` / `presentation`; состояние с полями `draft`, `deletedDraft`, `editCopy` | Принято без правок | Сверила со списком требований ТЗ и планом на семь дней |
| Каркас проекта, модель `Draft`, правила проверки, исходные данные | `draft.dart`, `draft_rules.dart`, `initial_draft.dart`; зависимости `flutter_bloc`, `equatable` | добавила go router | `flutter analyze` без ошибок, на экране показан «План кружка» |
| `DraftBloc`: сохранение, отмена, ошибка пустого заголовка | События `edit` / `save` / `cancel`, обработчики, временная копия `editCopy` | События, состояние и `DraftBloc` объединила в один файл; `DraftEvent` сделала обычным классом, не `sealed` | Ручные проверки 1–3 |
| Удаление и восстановление, пустое состояние | События `delete` / `restore`, экран «Черновик удалён», вывод `deletedDraft` в консоль через `onChange` | принято без правок | Ручные проверки 4–5, значения `deletedDraft` смотрела в консоли |
| Перенос строки в тексте, клавиатура «Done» вместо «return» | Объяснение: заголовок однострочный, перенос только в поле «Текст»; `textInputAction.newline` | добавила новый параметр TextInputAction.newline | Проверила в поле «Текст»: перенос строки работает, текст сохраняется в две строки |
